# evinf: Inference with Extreme Value Inflated Count Data

Allows users to model and draw inferences from extreme value inflated
count data, and to evaluate these models and compare them to their non
extreme-value inflated counterparts. The package is built to be
compatible with standard model-presentation tools such as the 'broom',
'generics', and 'modelsummary' packages.
