# Simulated data from the EVZINB distribution

A simulated dataset of 1,000 observations with one dependent and three
independent variables generated using the EVZINB distribution

## Usage

``` r
genevzinb
```

## Format

\## \`genevzinb\` A tibble with 1,000 rows and 4 columns:

- y:

  Dependent variable following the EVZINB distribution

- x1, x2, x3:

  Continuous independent variables following the standard normal
  distribution
